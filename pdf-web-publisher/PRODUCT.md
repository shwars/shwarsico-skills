# PDF Web Publisher

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Confirmed: static HTML, CSS, classic JavaScript, generated by a Python/uv helper.
No browser build step, backend, CDN, or required web server.

## Users

Authors publishing a public talk archive; visitors browsing talks and reading
slides on desktop or mobile. Authors choose a parent output directory.

## Product Purpose

Convert PDF pages into compressed imagery in a self-contained presentations
directory, usable by double-click or static hosting. Preserve a shared player
and add new talks to an editable JavaScript catalog. Catalog and per-deck slide
data each have one authoritative JavaScript file, without duplicate JSON copies.
Renaming a deck directory requires changing only its link in the main catalog.

## Capabilities and Constraints

PDF only. Default 1440 px long edge, WebP quality 55. Never copy source PDFs or
extract slide text into output. This deters casual copying but offers no access
control. Preserve existing unmanaged files. All published assets are local.

## Brand Commitments

Three confirmed themes: Programme (default, light gray/cobalt, cover-and-title
rows), Screening Room (charcoal, larger covers), Field Notes (mint, compact
numbered entries). The slide leads; the interface remains subordinate.

## Accessibility & Inclusion

Keyboard and touch navigation, labeled controls, visible focus, reduced motion,
Unicode metadata, responsive slide fitting. Images have slide-number labels;
source-content transcription is intentionally not exported.
