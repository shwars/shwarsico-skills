# Учебники в стиле Дмитрия Сошникова

Прочитай [профиль книжной прозы](references/textbook-style.md), [короткие фрагменты из книг](references/excerpts.md) и [правила вычитки](references/editorial-review.md). Примеры показывают, как автор ведёт рассуждение. Переноси этот ход на материал главы своими словами.

## Подготовить материал

Определи, какой результат нужен: новый текст, правка или разбор. Для главы учебника прочитай доступный паспорт, оглавление и те места соседних глав, от которых зависит объяснение. Используй принятые определения и обозначения, уровень подготовки читателя и уже знакомые примеры. Паспорт ведёт автор. Если доступен только фрагмент, опирайся на переданный контекст и укажи существенную неопределённость отдельно от рукописи. Уточняй лишь то, без чего можно изменить смысл или неверно выбрать исходные знания читателя.

## Написать или отредактировать

- **Написать.** Определи, что читатель узнает и какой ход сможет повторить. Для практической темы найди задачу и маленький пример с проверяемым результатом. Для формальной темы выбери посылки, порядок введения терминов и пример или вывод, который проясняет определение. Подача может меняться внутри главы. Длина разбора зависит от количества новых шагов.
- **Отредактировать.** Сохрани факты, ход мысли, авторские формулировки с ясной функцией, примеры и степень уверенности. Правь локально. Меняй устройство объяснения или вводи новый пример при явном запросе на переработку. Не приписывай автору биографию, мнения или наблюдения, которых он не сообщал.
- Выдавай рукопись в Markdown с формулами TeX. При правке сохраняй существующие формулы, код, обозначения и ссылки. Проверяй технические утверждения, результаты и границы применимости. Для нового учебного примера можешь выбрать вымышленные входные данные и самостоятельно вывести результат. Отмечай отдельно факты об условиях работы программы, которые остались непроверенными.

## Перечитать как редактор

Перечитай весь запрошенный материал. Сверь ход объяснения с профилем и пройди по признакам из памятки. Сопоставляй повторяющиеся зачины и финалы по всей главе. Для каждого подозрительного места выясни, что происходит с пониманием читателя при правке.

Запусти локальную проверку готового черновика или проверяемого файла. По возможности передай файл напрямую, чтобы замечания ссылались на его строки. Команда читает текст и выводит JSON.

```text
python <папка скилла>/scripts/check_style.py <глава.md> --register practical
python <папка скилла>/scripts/check_style.py - --format markdown --register theoretical
```

Для смешанного раздела выбери `mixed`. Для главы с явно разными по назначению частями сравни ритм частей отдельно, а связи и повторы оцени по главе целиком. Если Python недоступен, проверь те же места вручную. Вставленный текст можно передать через stdin в UTF-8. Скрипт также принимает обычный текст и исходный TeX, который использовался при анализе книг.

В режиме проверки верни замечания с местом, коротким фрагментом, конкретной причиной и направлением правки. Отмечай существенное расхождение, когда можешь показать его в тексте. Для наблюдения о ритме укажи измерение и книжный ориентир, если его можно сравнить. При отсутствии существенных замечаний так и скажи. В этом режиме рукопись остаётся для чтения.

В режимах написания и правки исправь подтверждённые замечания. Перечитай изменённые места вместе с окружением, затем сравни с исходными фактами, числами, формулами, кодом и оговорками. В чат верни готовый текст, при правке файла сохрани итог в нём. Подробный отчёт добавляй по просьбе автора.
