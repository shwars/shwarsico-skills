# Кукольный спектакль

Для web открыть `index.html` или разместить папку на статическом хостинге.
Для pygame запустить `run.cmd` (Python 3.11, первая установка требует сети).
На других ОС создать `.venv`, установить `requirements.txt`, запустить `main.py`.
При выборе одного движка файлы другого в проект не включаются.

Пробел — начать/пауза; вправо — раскрыть текст, затем следующая реплика;
1–9 — первые девять сцен; R — повтор. Все сцены доступны экранными кнопками.
В pygame Esc закрывает окно; в web — сворачивает полный экран.
В web доступны перемотка, скорость и полный экран; уход со страницы ставит паузу.

`script.json` и `assets/manifest.json` — исходные данные. После редактирования
использовать команду `prepare` из скилла sprite-theater. `data.js` и `fonts.css`
генерируются автоматически. Для просмотра подготовленного спектакля скилл,
исходная wiki, инструменты подготовки и сеть не нужны.

PT Sans включён с SIL Open Font License (`assets/fonts/OFL.txt`). Происхождение
изображений и связь с character sheet сохранены в манифесте, источники и
сценические допущения — в сценарии. У постановки без `--demo` нет тестовых картинок.
Если включён `--demo`, геометрические фигуры являются техническими fixtures,
созданными Pillow, и не представляют художественный результат GPT Images.
