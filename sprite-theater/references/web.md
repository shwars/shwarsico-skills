# Статический web

Создать `--backend web` либо `both`; редактировать общий сценарий/манифест,
после изменения выполнять `prepare`. Открывать `index.html` двойным щелчком
или размещать папку на обычном статическом хостинге, включая подкаталог.
Для просмотра Python/Node, установка пакетов и сборка не нужны.

`data.js` — производный classic script с `SpriteTheaterData`; не `fetch` JSON
и не ES modules. Это обеспечивает работу через `file://`. `fonts.css` содержит
локальный PT Sans как data URL. Не добавлять CDN, обязательные API, сервис-воркер
или сетевые шрифты. Не читать пиксели локального Canvas: `prepare` вычисляет
`bounds` заранее, чтобы избежать ограничений origin для локальных изображений.

`engine.js` вычисляет состояния и экспортируется также в CommonJS для проверок.
`renderer.js` рисует фон и фигурки. `app.js` управляет загрузкой, временем и HTML.
При ошибке ресурса показать понятную причину и повторную загрузку; поздний успех
другой картинки не должен стирать сообщение об ошибке. Старт доступен после
загрузки изображений и шрифта. Данные вставлять через `textContent`.

Баббл следует за головой, имя и текст остаются HTML. При фактической ширине
сцены менее 840 CSS px текст выносится под сцену. Сцену не обрезать под телефон.
Проверять промежуточные ширины и fullscreen, а не только media query телефона.

Пауза останавливает текст, движения и занавес. Перемотка сохраняет прежний
режим воспроизведения; уход со страницы отменяет автоматическое продолжение.
Возврат требует нажатия «Продолжить». Скорость: 0,75×, 1×, 1,25×, 1,5×, 2×.
Fullscreen использует браузерный API и полноэкранную компоновку как fallback.
Клавиши не перехватываются внутри input/select и не дублируют активацию кнопки.

Сохранять focus, native button/select/range, достаточные размеры touch-целей.
`aria-live` сообщает целую реплику один раз, не каждый печатающийся символ.
`prefers-reduced-motion` убирает декоративное покачивание и печать по буквам,
но сохраняет действия, смену поз и смысл постановки.

`SpriteTheater.seek(seconds)` ставит паузу и показывает заданный момент;
`SpriteTheater.inspect()` возвращает состояние для репетиции. Это локальный
диагностический интерфейс, не сетевой API.
