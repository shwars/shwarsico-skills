# Pygame

Создать `--backend pygame` либо `both`. Python 3.11 и pygame 2.6.1;
в проекте есть `requirements.txt`, `run.cmd`, `run.ps1`, `main.py` и `timeline.py`.
Лаунчер создаёт локальную `.venv`, сначала пробует `py -3.11`, затем `python`;
проверяет версию. После установки зависимостей сеть не нужна. Для других ОС:
`python3.11 -m venv .venv`, установка requirements и запуск `main.py` этим Python.

Окно по умолчанию 1280×720; логическая оболочка и сценическое разрешение
задаются сценарием. Сохраняются пропорции и поля. Цель — 60 FPS.
Пробел — начать/пауза, вправо — раскрыть текст/следующая реплика,
1–9 — первые девять сцен, R — повтор, Esc — выход. Экранные кнопки включают
переходы по всем сценам, даже если их больше девяти. Шкала позволяет перемотку.

`timeline.py` не зависит от pygame: часы, состояния и жесты проверяются отдельно.
Рендер вычисляется из времени; не запускать анимации отдельными таймерами.
PT Sans включён с OFL; для языка вне его покрытия заменить шрифт с лицензией
и проверить каждый используемый символ. Визуальные параметры — `presentation`.

Проверка без видимого окна:

```text
python main.py --headless --smoke-test --capture-dir qa
python main.py --headless --seek 7 --screenshot qa/frame.png --size 1280x720
```

`--smoke-test` проходит весь спектакль с шагом 0,5 с; это проверка состояний
и рендера, а не замер реального FPS. Для живого окна — `--run-for 5`.
