# Общие данные, версия 1

`init` создаёт `project.json` с выбранным backend, `script.json` и
`assets/manifest.json`. Пустой каркас намеренно не проходит `prepare`, пока
нет законченной сцены и её изображений. `--demo` создаёт отдельный исполнимый
технический пример; не заменять им заказанные иллюстрации.

## Сценарий

Корень: `version: 1`, `title`, `subtitle`, `end_title`, `characters`,
`adaptation_notes`, `scenes`. `stage` содержит целые `width`, `height`, скорость
текста `chars_per_second` и длительность открытия/закрытия `curtain_seconds`.
По умолчанию сцена 1516×680, оболочка 1600×900 (`presentation.logical_size`).
`presentation.theme` задаёт цвета `paper`, `ink`, `gold`, `curtain` как `#RRGGBB`.
Неизвестные визуальные детали остаются решениями конкретной постановки.

`characters` — словарь по ID. Значения: `name`, `entity_id` и `color`.
Для говорящего рассказчика добавить `narrator`; в actors он не обязателен.
Сцена: уникальный `id`, `title`, `duration`, ID `background`, массивы `actors`,
`props`, `cues`. Необязательный `caption: {at, text}` — сценическая подпись.
Число сцен произвольное; длительности определяют общее время автоматически.

Фигура: `id` персонажа, `asset`, `height` в логических пикселях сцены, `z`,
`keyframes`, необязательный `gestures`. Реквизит имеет тот же формат, но собственный
ID и может иметь `attach` — ID актёра. Персонажи не прикрепляются друг к другу.
Идентификаторы предметов и актёров в пределах сцены не повторяются.

Ключевые кадры начинаются с `at: 0`, время строго возрастает и не выходит за сцену.
`x`, `y` — доли ширины и высоты сцены относительно точки привязки. Для прикреплённого
реквизита — смещение от текущей точки актёра. Числовые `x`, `y`, `angle` (градусы),
`scale`, `width_scale` плавно интерполируются к следующему кадру; scale положителен.
`asset`, `visible`, `flip`, `attach` меняются строго в момент кадра.
`attach: null` освобождает реквизит; в том же кадре явно указать мировые x/y.
Для присоединения указать локальные x/y. `tween: false` в целевом кадре отключает
числовую интерполяцию к нему (полезно при смене системы координат).
Неуказанные поля наследуются из предыдущих кадров; восстановление не зависит
от ранее просмотренных кадров. Начальная y по умолчанию .94, x — 0.

`gestures`: `{kind, at, duration}`. Встроены `bow`, `recoil`, `tangle`, `lift`;
для сложного действия сочетать жест, изменение позиции и нужную позу.
Покачивание шага и речи декоративное; при reduced motion отключается.

Реплика: уникальный во всём спектакле `id`, `speaker`, `at`, `duration`, `text`,
`sources`, `adaptation`. Реплики сцены идут по времени и не пересекаются.
`original: true` разрешает пустой sources для честно обозначенной авторской вставки.
Оставлять время на прочтение после раскрытия текста и не помещать диалог под
закрытый занавес. Источник и сведения о сокращении не показываются по буквам.

## Манифест

Корень: `version: 1`, `fonts: {regular, bold, license}` (локальные пути), `assets`.
Ассет имеет `file`, `kind` (`character`, `prop`, `background`) и `provenance`:
`generator`, `prompt_file`, `references` (пути локальных копий референсов).
Пути файлов относительны проекту, с `/`; абсолютные, сетевые и выходящие за
проект пути не допускаются. `sheet_origin.path` — только запись происхождения,
поэтому исходный путь общей wiki может быть внешним.

Для фигур и реквизита нужны PNG с настоящей прозрачностью и `anchor: [x,y]`.
Для фигуры также `head_anchor`, `sheet`, `sheet_metadata`, `sheet_origin`
(`entity_id`, `profile`, `version`, `path`). Anchor и head_anchor — доли **видимой
области после обрезки прозрачных полей**, от 0 до 1, а не исходного PNG.
Высота фигуры относится к этой же области. Обычно anchor `[.5,1]`.
При отражении точки привязки отражаются вместе с фигурой.

`prepare` вычисляет `size`, `bounds: [left,top,right,bottom]` по alpha >=16 и
`sha256`, затем обновляет манифест. Исходные изображения не изменяет.
Проверяет наличие sheet/метаданных/промпта, совпадение личности поз и персонажа,
реальные alpha-пиксели и локальность ресурсов. Край, касающийся границы PNG,
вызывает предупреждение: нужен визуальный контроль, а не автоматическое обрезание.
Это не доказательство сходства с листом и не проверка источников по содержанию.

`prepare` для web также записывает classic-script `data.js` и встроенный шрифт.
`validate` ничего не пишет и обнаруживает устаревшие данные после правки сценария,
изображений или шрифта. Не редактировать производный data.js вручную.
