# Идентичность, новые книги и миграции

## Перед созданием

Искать по `entity_id`, заголовку, `aliases`, вариантам написания/транслитерации,
титулу, роли, родственным связям и контексту. Проверять возраст/поколение,
место и время. Использовать Markdown и `wiki.cards()`; JSON актуален только
после успешной сборки.

Фамилия, должность или похожее описание не доказывают тождество. Читаемые
уточнения лучше технических номеров. Не объединять людей независимых циклов
или прототип с вымышленным человеком автоматически. При неопределённости
оставить вопрос и раздельные кандидаты; не создавать третью личность для
неоднозначной подписи между двумя известными людьми.

Прямое узнавание безымянного персонажа может обосновать объединение. Повторные
рассказы об одном событии обогащают его карточку и `occurrences`; противоречия
остаются отдельными фактами с источниками и статусами.

## Следующая книга

Сохранить установленный книжный суффикс и ID. Вызвать `authoring.set_book`,
добавить сведения с новыми источниками и `book_ids`; дописать ручной раздел
«Далее из другой книги: <название>». Не заменять старое состояние новым.

Для того же утверждения расширить источники существующего факта, сохранив ID;
отдельные временные состояния и противоречивые версии требуют новых записей.
Не дублировать факт ради раздела. Номера фактов не означают порядок событий.

## Историческое лицо становится книжным

`.hist.md` у человека означает отсутствие упоминаний в обработанном основном
тексте. Прямого упоминания достаточно; редакционное примечание не подходит.
Добавить факт `scope: canon` с блоком основного текста, затем выполнить:

```text
python /skill/scripts/wiki.py --root /vault promote-person "Имя" --book-id book2 --dry-run
python /skill/scripts/wiki.py --root /vault promote-person "Имя" --book-id book2 --apply
```

Сохраняются ID и исторический текст, меняются суффикс, `first_source`, `book_ids`.
Переписываются точные Obsidian-ссылки, встраивания, Markdown-ссылки и reference
definitions, включая YAML/facts, переносы YAML, URL-кодированные пути, подписи,
заголовки и block anchors. Похожая проза и все `.hist` подряд не заменяются;
относительный смысл пути сохраняется. Коллизия запрещает запись.

Preview — техническая проверка, не обязательный запрос нового разрешения
в уже порученном индексировании. Применение пересобирает проекции; повторная
команда безопасна. Установленный книжный суффикс позже сохраняется.
При обработке книг вне порядка не менять его без явного решения о миграции.

## Доказанные дубли

Вне `wiki.authoring_batch()` использовать сохранённые помощники:

```python
import card_migration
kwargs = dict(identity_sources=[wiki.ref("book2", "p01-ch02", "b0012")],
              explanation="Рассказчик прямо раскрывает имя того же человека.")
preview = card_migration.merge_people(wiki, "Софья", "Незнакомка у ворот",
                                      apply=False, **kwargs)
# Проверить preview, затем применить в пределах порученной работы.
result = card_migration.merge_people(wiki, "Софья", "Незнакомка у ворот", **kwargs)
wiki.build()
```

`merge_concepts` объединяет концепты одинакового типа; `merge_people` проверяет
тип персонажа. Сохраняется ID основной карточки, ID дубля становится alias.
ID фактов дубля сохраняются, даже когда префикс отличается от нового субъекта.
Входящие ссылки и адресуемые поля фактов обновляются, текст и появления
объединяются. Дубль удаляется без redirect. Повтор возвращает `already-merged`.

Идентичность устанавливает агент по тексту; непустое пояснение само по себе
не доказательство. После применения проверить реестр, ссылки, отсутствие
дубля, сохранность фактов, сборку и `validate`.

Миграции вычисляют изменения до записи, проверяют коллизии и конкурентные правки,
записывают файлы атомарно и откатывают ошибки записи. Это не транзакция при
аварийном отключении: после прерывания сверить фактическое состояние.

Для переименования без изменения личности есть готовый механизм
`card_migration.rewrite(text, page, old, new, root)`: вычислить все правки,
исключить перезапись назначения, сохранить ID, обновить точные цели и проверить
отсутствие старых ссылок. Универсальной CLI-команды переименования здесь нет.
