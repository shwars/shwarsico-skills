# Image Prompt Library

Библиотека визуальных промптов для стилизации фотографий. Каталог для ассистента находится в [SKILL.md](SKILL.md).

## Стили

| Стиль | Результат |
| --- | --- |
| [Abstract Poster](references/abstract-poster.json) | Горизонтальный постер 3:2. Геометрический символ передаёт характер исходной фотографии, а фактура напоминает аналоговую печать. |
| [Fashion Portrait](references/fashion-portrait.txt) | Свободный маркерный скетч, который сохраняет позу, композицию и узнаваемые черты лица с фотографии. |
| [Big-Eyed Creature](references/big-eyed-creature.md) | Большеглазый персонаж, нарисованный восковыми мелками. Глаза могут смотреть в одном направлении или в разные стороны. Выражение лица выбирается отдельно. |
